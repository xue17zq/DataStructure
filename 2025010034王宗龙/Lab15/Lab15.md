## 二、单层循环中的倍增推进（题 1）

### 题 1（2011 年）

设 n 是描述问题规模的非负整数，下面程序片段的时间复杂度是（ ）。

```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```

- [x] A. O(log₂n)
- [ ] B. O(n)
- [ ] C. O(nlog₂n)
- [ ] D. O(n²)

## 三、递归算法的时间复杂度（题 2）

### 题 2（2012 年）

求整数 n(n≥0) 阶乘的算法如下，其时间复杂度是（ ）。

```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

- [ ] A. O(log₂n)
- [x] B. O(n)
- [ ] C. O(nlog₂n)
- [ ] D. O(n²)

## 六、平方根级循环（题 6～7）

### 题 6（2017 年）

下列函数的时间复杂度是（ ）。

```c
int func(int n) {
    int i = 0, sum = 0;
    while(sum < n)
        sum += ++i;
    return i;
}
```

- [ ] A. O(log₂n)
- [x] B. O(√n)
- [ ] C. O(n)
- [ ] D. O(nlog₂n)

### 题 7（2019 年）

设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```

- [ ] A. O(log₂n)
- [x] B. O(√n)
- [ ] C. O(n)
- [ ] D. O(n²)
