### 2.1 单层循环

```c
long long algorithm1(int n) {
    long long count = 0;

    for (int i = 0; i < n; i++) {
        count++;
    }

    return count;
}
```

该算法中 `count++` 的执行次数 `T(n)` 和时间复杂度分别是：

- [ ] A. `T(n) = 1`，时间复杂度为 **`O(1)`**
- [x] B. `T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] C. `T(n) = n²`，时间复杂度为 **`O(n²)`**
- [ ] D. `T(n) = log₂n`，时间复杂度为 **`O(log n)`**

### 2.2 内层次数随外层变化的循环

```c
long long algorithm2(int n) {
    long long count = 0;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            count++;
        }
    }

    return count;
}
```

该算法中 `count++` 的执行次数 `T(n)` 和时间复杂度分别是：

- [ ] A. `T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] B. `T(n) = n(n - 1) / 2`，时间复杂度为 **`O(n²)`**
- [x] C. `T(n) = n(n + 1) / 2`，时间复杂度为 **`O(n²)`**
- [ ] D. `T(n) = n log₂n`，时间复杂度为 **`O(n log n)`**

### 2.3 倍增循环

```c
long long algorithm3(int n) {
    long long count = 0;

    for (int i = 1; i < n; i *= 2) {
        count++;
    }

    return count;
}
```

假设 `n = 2ᵏ`，该算法中 `count++` 的执行次数 `T(n)` 和时间复杂度分别是：

- [x] A. `T(n) = k`，时间复杂度为 **`O(log n)`**
- [ ] B. `T(n) = n / 2`，时间复杂度为 **`O(n)`**
- [ ] C. `T(n) = n²`，时间复杂度为 **`O(n²)`**
- [ ] D. `T(n) = 2ᵏ`，时间复杂度为 **`O(n)`**

### 2.4 单层循环与倍增循环组合

```c
long long algorithm4(int n) {
    long long count = 0;

    for (int i = 0; i < n; i++) {
        for (int j = 1; j < n; j *= 2) {
            count++;
        }
    }

```

假设 `n = 2ᵏ`，该算法中 `count++` 的执行次数 `T(n)` 和时间复杂度分别是：

- [ ] A. `T(n) = k`，时间复杂度为 **`O(log n)`**
- [ ] B. `T(n) = n²`，时间复杂度为 **`O(n²)`**
- [ ] C. `T(n) = n + k`，时间复杂度为 **`O(n)`**
- [x] D. `T(n) = nk`，时间复杂度为 **`O(n log n)`**

## 四、最好情况与最坏情况

阅读下面的顺序查找函数：

```c
int find(const int array[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (array[i] == target) {
            return i;
        }
    }

    return -1;
}
```

将数组元素与 `target` 的比较视为基本操作，完成以下单项选择题。

### 4.1 最好情况

顺序查找的最好情况是：

- [ ] A. `target` 位于数组最后一个位置，比较 `n` 次，`T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] B. 数组中不存在 `target`，比较 `0` 次，`T(n) = 0`，时间复杂度为 **`O(1)`**
- [x] C. `target` 位于数组第一个位置，比较 `1` 次，`T(n) = 1`，时间复杂度为 **`O(1)`**
- [ ] D. `target` 位于数组中间位置，比较 `n²` 次，`T(n) = n²`，时间复杂度为 **`O(n²)`**

### 4.2 最坏情况

当 `target` 位于数组最后一个位置，或者数组中不存在 `target` 时，以下说法正确的是：

- [x] A. 两种情况都需要比较 `n` 次，最坏情况下 `T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] B. 前者比较 `1` 次，后者比较 `n` 次，最坏情况下时间复杂度为 **`O(1)`**
- [ ] C. 两种情况都需要比较 `n²` 次，最坏情况下时间复杂度为 **`O(n²)`**
- [ ] D. 前者比较 `n / 2` 次，后者不需要比较，最坏情况下时间复杂度为 **`O(log n)`**

### 4.3 最好情况和最坏情况不同的原因

为什么同一段顺序查找代码会有不同的最好情况和最坏情况，并且分析算法效率时通常需要特别关注最坏情况？

- [ ] A. 因为 C 编译器会随机决定循环执行次数，最坏情况代表编译失败
- [x] B. 因为目标值的位置或是否存在会影响比较次数，而最坏情况能够给出算法所需时间的上界保证
- [ ] C. 因为数组长度在程序运行过程中会自动改变，最坏情况代表数组长度为 `0`
- [ ] D. 因为最好情况只出现在 C++ 中，C 语言程序只需要分析最坏情况
